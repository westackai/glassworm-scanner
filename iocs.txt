## DETECTION NOTE — invisible Unicode is NOT how this incident's payload hides
# Public GlassWorm coverage centres on invisible-Unicode variation selectors.
# The live sample pulled from courtpass/kiosk-app on 2026-08-17 contains ZERO
# variation selectors. It is plain obfuscator.io output padded with ~350 leading
# spaces so it renders blank. So a Unicode-only scanner will not flag it — this
# toolkit detects it by file identity + `file` type (a "font" that is ASCII).
#
# When you DO hunt invisible Unicode, require a RUN of 8+ consecutive selectors.
# One selector encodes one byte, so real payloads run to hundreds, while a lone
# selector is an emoji modifier or BOM. Measured locally: python's
# unicode/category/Mn.js has 256 selectors but longest run 1; Volar peaks at 3.
# Also: BSD grep on macOS cannot match these byte ranges at all — use perl.
